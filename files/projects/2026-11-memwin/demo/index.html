Which frames does one MemWin window encode?

Every block of L frames is encoded together with the query frame and M memory frames spread over the whole past. The window size stays at 1 + M + L frames however long the video gets.

Each window is then run through the frozen query model, and its predictions are rescaled by the median ratio of the query points' frame-0 depth in the first window to that in this window, so every block shares one scale. On validation, replacing the spread memory by the 8 most recent block ends recovers only 34% (UniQuery4R) and 43% (OpenD4RT) of the accuracy lost without memory.
